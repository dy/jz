Start with a function you already have.

  1. Install

    npm install jz

    Or try it first in the playground, nothing to install.

  2. Compile a function

    No annotations: types are read off the arithmetic.

    import jz from 'jz'

const { exports } = jz`
  export const dist = (x, y) =>
    (x*x + y*y) ** 0.5
`

console.log(exports.dist(3, 4)) // 5

  3. Pass whole arrays

    Each crossing into WASM costs; hand it a batch, not one number.

    import jz from 'jz'

const { exports, memory } = jz`
  export const sum = a => {
    let total = 0
    for (const x of a) total += x
    return total
  }
`

const values = new Float64Array([1, 2, 3])
console.log(exports.sum(values)) // 6
memory.reset()

  4. Ship the .wasm

    The compiler stays in the build; the page loads a 13 KB runtime.

    npx jz kernel.js               # → kernel.wasm
npx jz kernel.js -O3           # fastest; -Os smallest
npx jz kernel.js --host wasi   # standalone WASI module
npx jz kernel.js --why         # what kept a loop scalar
    import { instantiate } from 'jz/interop'

const wasm = await fetch('kernel.wasm').then(r => r.arrayBuffer())
const { exports } = instantiate(wasm)

  5. Check both

    Testsrun them against kernel.js and kernel.wasm
    Speedtime the whole call, transfer included
    Scalar loops--why names the operation that blocked SIMD
