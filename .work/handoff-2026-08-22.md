## Warm-pin bisect + opaque dispatch recovery — complete

- The local timing environment was not quiet: four orphaned `strbuild` bench
  binaries had each consumed one full core continuously for 8–11 days. They
  were terminated by PID. Even afterwards the stopwatch ratio remained
  thermally/JIT-sensitive: the identical Aug-16 `6adde429` artifact measured
  1.025× warm, then 1.108–1.161× later with no source change. The strict cap
  was not loosened and no commit was classified from an unpaired stopwatch.
- Same-process, order-alternated artifact A/B isolated the source signal. The
  campaign baseline `11588771` was 0.987× and pre-opaque `b028ea65` was 0.994×
  versus the Aug-16 artifact: the representation campaign had not regressed
  warm Wasm. The merged opaque tree was 1.041× versus `b028ea65`, localizing
  the real regression entirely to the new length path.
- Root cause had two general parts. Numeric use called
  `__length_num → __length → __to_num`, repeating dispatch on ARRAY hot paths;
  and `.length` read `rep ? rep.val : valTypeOf`, so the mere existence of an
  unrelated durable rep hid higher-priority flow facts. Thus the canonical
  compiler shape `if (!Array.isArray(node)) return; node.length` stayed
  polymorphic thousands of times.
- Source commit 8616e2b2 restores lookup priority via `lookupValType`, splits
  raw `__length.value` from numeric `__length` while generating both from one
  source, and outlines ToNumber to the ordinary-property tail. ARRAY/TYPED/
  STRING never pay it. Immediately paired against `b028ea65`, the repaired
  artifact is 1.011× (merged opaque: 1.041×), recovering about three percentage
  points while preserving object/host/nullish semantics. dist/jz.wasm shrinks
  16,956.2→16,949.1 kB.
- Rebuilt validation: native full suite 3638/3636/0/2; test:wasm
  2891/2889/0/2; self-compile 21/21; parity 3/3; oracle 14/14; ratchet 10/10.
  Fresh-instance remains green at 0.838–0.847×. The V8-referenced warm stopwatch
  still reads 1.037–1.067× on this active GUI machine; direct artifact A/B is
  the authoritative attribution result, not grounds to relax the 1.03 cap.

## Process rules that kept this sound (binding for any resumer)

- Serial merges only; every branch validates its MERGE PRODUCT (merge
  main into branch, rebuild, battery) before merging back; bar = ZERO
  fails at the current suite total. Build before suites (stale dist =
  false fails). pwd-verify before every git/build/test command.
- Git safety: no repo-wide commands (stash/checkout/reset/clean/switch/
  restore), stage named files only, user is sole author (no
  Co-Authored-By / Generated-with), never push/pull — the user pushes.
- .work/todo-original.md in the main worktree belongs to the user.
- Agents: never park on background-wake promises (they die); hold turns
  with chained bounded-wait loops (`for i in $(seq 1 27); do <check> &&
  break; sleep 15; done`, immediately followed by the next). Zombie
  recovery that works: TaskStop, then SendMessage (resumes from
  transcript at the exact stall point). Dead-man watch: file-driven
  watchlist + transcript-mtime staleness + main-HEAD moves
  (scratchpad/deadman10.sh pattern).
- Bench/demo sources are fixed specimens: fix the engine, never the
  input. Wrong-value classes outrank performance work. KNOWN-WRONG pins
  are trail markers with named flip conditions — zero allowed at release
  on semantic paths.
