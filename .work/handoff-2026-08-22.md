  main into branch, rebuild, battery) before merging back; bar = ZERO
  fails at the current suite total. Build before suites (stale dist =
  false fails). pwd-verify before every git/build/test command.

  restore), stage named files only, user is sole author (no
  Co-Authored-By / Generated-with), never push/pull — the user pushes.

- Agents: never park on background-wake promises (they die); hold turns
  with chained bounded-wait loops (`for i in $(seq 1 27); do <check> &&
  break; sleep 15; done`, immediately followed by the next). Zombie
  recovery that works: TaskStop, then SendMessage (resumes from
  transcript at the exact stall point). Dead-man watch: file-driven
  watchlist + transcript-mtime staleness + main-HEAD moves
  (scratchpad/deadman10.sh pattern).
- Bench/demo sources are fixed specimens: fix the engine, never the
  input. Wrong-value classes outrank performance work. KNOWN-WRONG pins
  are trail markers with named flip conditions — zero allowed at release
